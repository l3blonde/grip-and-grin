# Grip & Grin - Classical Cars News Website
A modern PHP news website focused on classical cars, built using clean architecture principles and contemporary PHP practices. 
This project was developed following guidelines from "Modern PHP: New Features and Good Practices" by Josh Lockhart.

**Live Website:** http://www.gripandgrin.org

## Features
- Homepage with paginated article listings (5 per page) with with next/previous navigation
- Individual article pages with next/previous navigation
- Search functionality across titles and content
- User registration and secure login with password hashing
- Personal profile pages with session management
- Admin dashboard for article management (create, edit, delete, publish)
- User management and role-based access control
- Responsive design with clean HTML/CSS
- Database-driven content with comprehensive error handling

### Technical Features
- Clean architecture with separation of concerns
- Modern PHP practices and security measures
- Database-driven content management
- Comprehensive error handling and validation

## Technical Stack
- **Language:** PHP 8+
- **Architecture:** Clean Architecture with Domain-Driven Design
- **Database:** MySQL
- **Hosting:** Linode VPS
- **Version Control:** Git (GitHub)

## Database Structure
The application distinguishes between regular users and administrators, with articles containing publication status controls and comprehensive content management capabilities.

## Deployment
Hosted on Linode infrastructure with proper SSL certification and domain configuration through Cloudflare DNS management.
